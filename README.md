# Steelcase Media Plan (ID, CN, SG) July 2026

Interactive, high-fidelity web proposal page replicating the FuseBase / Nimbus proposal format (`go.steelcase.com/july2026_mediaplan`).

## Files
- `index.html`: Fully semantic document structure with complete budget tables, channel strategies, benchmarks, and targeting criteria.
- `styles.css`: Modern design system featuring glassmorphic navigation, sticky headers, responsive tables, and Light/Dark mode support.
- `app.js`: Dark mode toggle, ScrollSpy navigation highlighting, and 1-click Print/PDF export.

## 🚀 How to Host on GitHub Pages (Public & Free in 2 Minutes)

GitHub Pages is the easiest, zero-maintenance way to host this page with a fast, public link.

### Option A: Using the Terminal / Git CLI (Fastest)

1. Open Terminal in this folder:
   ```bash
   cd "/Users/arden/Documents/- Ai Software builts/-MediaProposal"
   ```

2. Initialize git and commit:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Steelcase July 2026 Media Plan"
   git branch -M main
   ```

3. Create a new repository on [GitHub](https://github.com/new) named `steelcase-mediaplan` (choose **Public**).

4. Link and push:
   ```bash
   git remote add origin https://github.com/<YOUR-USERNAME>/steelcase-mediaplan.git
   git push -u origin main
   ```

5. **Enable GitHub Pages:**
   - Go to your repository on GitHub: `https://github.com/<YOUR-USERNAME>/steelcase-mediaplan`
   - Click **Settings** (top tab) → **Pages** (left sidebar).
   - Under **Build and deployment** → **Source**, select **Deploy from a branch**.
   - Under **Branch**, select `main` and `/ (root)`, then click **Save**.
   - Your live public URL will be ready in ~30 seconds:
     **`https://<YOUR-USERNAME>.github.io/steelcase-mediaplan/`**

---

### Option B: Using GitHub Web (No Terminal Needed)

1. Go to [github.com/new](https://github.com/new) and create a repository (e.g. `steelcase-mediaplan`), set it to **Public**.
2. Click **uploading an existing file** on the empty repository page.
3. Drag and drop `index.html`, `styles.css`, `app.js`, and `README.md` into the browser.
4. Click **Commit changes**.
5. Go to **Settings** → **Pages** → under **Branch** choose `main` / `root` → click **Save**.
